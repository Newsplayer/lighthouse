Sponsorship data

Lighthouse can show each employer's visa-sponsorship history from free government data. Download the files, then import them here.

  • DOL LCA disclosure data (quarterly .xlsx): dol.gov › Foreign Labor › Performance data → “LCA Programs (H-1B, H-1B1, E-3)”.
  • USCIS H-1B Employer Data Hub (annual .csv): uscis.gov › H-1B Employer Data Hub.

Or drop files into {{ folder }} and click Import with no file selected. Large LCA spreadsheets take a few minutes.
